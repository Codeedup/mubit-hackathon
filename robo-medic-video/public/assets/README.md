# Video assets

Put the real app screen recording, N20 motor/servo hardware clip, and any approved Mubit status evidence in this folder. Keep original files so the Remotion composition can use them directly.

The draft composition recognizes these exact filenames automatically:

- `app-incident.mp4` — real incident view
- `app-diagnosis.mp4`
- `app-feedback.mp4` — technician outcome flow
- `hardware-rig.mp4`
- `mubit-dashboard-2026-10-24.png` — Mubit dashboard at 14:33, showing requests and adapters serving
- `mubit-tasks-2026-10-24.png` — supplied task screenshot at 23:30, showing review progress
- `narration.mp3` — optional voiceover

The `demo-*.png` files are app captures used in the current rendered demo. The
`demo-voice-*.wav` files are generated draft narration. When a named recording
or Mubit evidence image above is added, the composition uses it in place of the
corresponding capture. `hardware-rig.mp4` replaces the labelled illustration.

Use only genuine footage and evidence. If an asset shows synthetic data, label it as synthetic in the video.
The app and hardware recordings play muted by default. After adding footage, review
the timing, trim or split each clip as needed, and crop into small interface details.
